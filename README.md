# ARNIX LAMPA Android

Android-клиент Lampa на Kotlin с локально встроенной сборкой оригинального веб-приложения Lampa.

## Как собирается приложение

GitHub Actions при каждом push в `main` или вручную:
1. Получает Android-проект.
2. Получает оригинальные исходники из `yumata/lampa-source`.
3. Собирает Lampa командой `npx gulp pack_github`.
4. Копирует собранный интерфейс и GPL-лицензию в Android assets.
5. Собирает APK через Gradle и публикует его как Actions Artifact.

## Технологии

- Kotlin / Android WebView
- WebViewAssetLoader — локальная загрузка встроенных файлов через appassets origin
- Оригинальный JavaScript-код Lampa и её веб-система плагинов
- Ограниченный AndroidJS-мост для Android-интеграции
- AndroidX WebKit
- AndroidX Media3 / ExoPlayer с HLS-модулем для нативного воспроизведения переданных ссылок

## Текущий статус

- Оригинальная веб-сборка Lampa включается в APK на этапе CI.
- Lampa открывается из локальных Android assets, а не с удалённого сайта.
- Базовый вызов `AndroidJS.openPlayer(link, data)` передаёт ссылку в полноэкранный Media3-плеер.
- Открытие внешних ссылок и magnet-ссылок передаётся Android-приложениям.

Это ещё не полная реализация всех методов оригинального AndroidJS API. Плагины, использующие дополнительные нативные методы, специальные заголовки, субтитры или нестандартные схемы воспроизведения, требуют дальнейшей интеграции и тестирования на устройстве.

## Сборка APK

Откройте вкладку **Actions** репозитория и выберите **Build ARNIX LAMPA APK**. После успешного завершения APK будет в разделе Artifacts соответствующего запуска.
