# ARNIX LAMPA Android

Android-клиент Lampa на Kotlin с локально встроенной сборкой оригинального веб-приложения Lampa.

## Как собирается приложение

GitHub Actions при каждом push в `main` или вручную:
1. Получает этот Android-проект.
2. Получает оригинальные исходники из `yumata/lampa-source`.
3. Собирает Lampa командой `npx gulp pack_github`.
4. Копирует результат в Android assets.
5. Собирает APK через Gradle и публикует его как Actions Artifact.

## Технологии

- Kotlin / Android WebView
- WebViewAssetLoader — локальная загрузка исходников по HTTPS-подобному origin
- Оригинальные исходники Lampa (собираются из upstream на CI)
- AndroidX WebKit
- Media3 dependencies подготовлены для следующего этапа нативного видеоплеера

## Важно

Встроенный интерфейс — оригинальная сборка Lampa, а не удалённый сайт-заглушка. При этом не каждый сторонний плагин гарантированно совместим: плагины, использующие специальные AndroidJS API, требуют реализации соответствующих методов моста. Нативный Media3-плеер и полный набор AndroidJS API пока не подключены.

Оригинальный исходный код: https://github.com/yumata/lampa-source. Соблюдайте лицензию и сохраняйте уведомления авторов при распространении производных сборок.
